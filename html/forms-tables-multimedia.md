
# HTML5 - Forms, Tables and Multimedia

## 1. HTML Forms

Forms collect information from users.

Main form elements:

- `<form>` - Form container
- `<label>` - Input description
- `<input>` - Input field
- `<textarea>` - Multiline text
- `<button>` - Button
- `<select>` - Dropdown
- `<option>` - Dropdown option

## 2. HTML Input Types

| Type | Purpose |
|---|---|
| text | General text |
| password | Password |
| email | Email address |
| number | Numeric input |
| tel | Telephone number |
| date | Date selection |
| time | Time selection |
| radio | Single selection |
| checkbox | Independent selections |
| file | File selection |
| submit | Form submission |
| search | Search input |
| url | Website address |

## 3. Radio Buttons and Checkboxes

Radio buttons usually allow one selection within a group.

Checkboxes allow independent selections.

Radio buttons in the same group share the same name attribute.

## 4. Dropdown and Textarea

- `<select>` creates a dropdown.
- `<option>` defines an option.
- `<textarea>` accepts multiline text.

## 5. Form Attributes

| Attribute | Purpose |
|---|---|
| name | Identifies submitted data |
| id | Identifies an element |
| value | Defines a value |
| placeholder | Displays a hint |
| required | Makes a field mandatory |
| readonly | Prevents editing |
| disabled | Disables an element |
| min | Minimum value |
| max | Maximum value |
| maxlength | Maximum text length |
| autocomplete | Controls autofill |

## 6. HTML Tables

| Element | Purpose |
|---|---|
| table | Table container |
| tr | Table row |
| th | Header cell |
| td | Data cell |
| thead | Header group |
| tbody | Body group |
| tfoot | Footer group |
| caption | Table title |

### Colspan and Rowspan

- colspan allows a cell to span multiple columns.
- rowspan allows a cell to span multiple rows.

## 7. HTML Audio

The `<audio>` element embeds audio.

Important attributes:

- controls
- autoplay
- loop
- muted
- preload

## 8. HTML Video

The `<video>` element embeds video content.

Important attributes:

- controls
- width
- height
- poster
- autoplay
- loop
- muted

## 9. HTML Iframes

The `<iframe>` element embeds another webpage or external resource.

Common uses include maps, videos and external applications.

## 11. HTML Accessibility

Important practices:

- Use meaningful alt text for images.
- Connect labels with form inputs.
- Use semantic HTML.
- Use meaningful link text.
- Maintain a logical heading hierarchy.
- Ensure content can be accessed using a keyboard.

## 12. HTML Meta Tags

Meta tags provide information about a webpage.

Common meta tags:

- charset
- viewport
- description
- author

They are placed inside the `<head>` element.
