
# HTML5 Fundamentals

HTML stands for HyperText Markup Language.

It is used to structure content on webpages.

## 1. HTML Tags, Elements and Attributes

- Tag: A keyword enclosed in angle brackets.
- Element: An HTML structure consisting of tags and content.
- Attribute: Additional information provided to an element.

Example:

```html
<a href="https://github.com">GitHub</a>
```

## 2. HTML Document Structure

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>My Website</title>
</head>
<body>
    <h1>Hello World</h1>
    <p>Welcome to my website.</p>
</body>
</html>
```

## 3. HTML Headings

HTML provides six heading levels.

- `<h1>` Main heading
- `<h2>` Secondary heading
- `<h3>` Third-level heading
- `<h4>` Fourth-level heading
- `<h5>` Fifth-level heading
- `<h6>` Sixth-level heading

## 4. Paragraphs and Text Formatting

```html
<p>This is a paragraph.</p>
<strong>Important text</strong>
<em>Emphasized text</em>
<b>Bold text</b>
<i>Italic text</i>
<mark>Highlighted text</mark>
<small>Smaller text</small>
<del>Deleted text</del>
```

## 5. HTML Links

```html
<a href="https://github.com">Visit GitHub</a>
```

The `href` attribute specifies the destination.

## 6. HTML Images

```html
<img src="profile.jpg" alt="Profile photo">
```

- `src`: Image location.
- `alt`: Alternative text.
- `width`: Image width.
- `height`: Image height.

## 7. HTML Lists

Unordered list:

```html
<ul>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ul>
```

Ordered list:

```html
<ol>
    <li>Learn HTML</li>
    <li>Learn CSS</li>
    <li>Learn JavaScript</li>
</ol>
```

## 8. HTML Comments

```html
<!-- This is a comment -->
```

Comments are not displayed as webpage content.

## 9. HTML Nesting

Nesting means placing an HTML element inside another element.

```html
<div>
    <h1>My Profile</h1>
    <p>Welcome to my website.</p>
</div>
```

Elements should be closed in the correct order.

## 10. Block and Inline Elements

Block elements generally start on a new line.

Examples:
- `<div>`
- `<p>`
- `<h1>`
- `<section>`

Inline elements generally remain within the same line.

Examples:
- `<span>`
- `<a>`
- `<strong>`
- `<em>`

## 11. Semantic HTML

Semantic elements describe the purpose of webpage content.

| Element | Purpose |
|---|---|
| `<header>` | Page header |
| `<nav>` | Navigation |
| `<main>` | Main content |
| `<section>` | Thematic section |
| `<article>` | Independent content |
| `<aside>` | Complementary content |
| `<footer>` | Page footer |

## 12. HTML5 Features

- Semantic elements
- Audio and video support
- Improved forms
- Canvas graphics
- Modern web application support
