
# How Websites Work

## 1. Website

A website is a collection of related web pages and resources accessible through a domain name.

## 2. Web Page

A web page is an individual document displayed in a web browser.

## 3. URL

URL stands for Uniform Resource Locator.

A URL identifies the location of a resource on the Internet.

Example:

https://www.example.com/products?id=10

Main components:
- Protocol
- Subdomain
- Domain
- Path
- Query parameters

## 4. Website Loading Process

1. User enters a URL.
2. Browser processes the URL.
3. DNS resolves the domain name.
4. Browser establishes a connection.
5. Browser sends an HTTP request.
6. Server returns an HTTP response.
7. Browser processes website resources.
8. Browser renders the webpage.

## 5. HTTP Methods

| Method | Purpose |
|---|---|
| GET | Retrieve data |
| POST | Submit data |
| PUT | Replace a resource |
| PATCH | Partially update a resource |
| DELETE | Delete a resource |

## 6. HTTP Status Codes

| Code | Meaning |
|---|---|
| 200 | OK |
| 201 | Created |
| 301 | Permanent Redirect |
| 400 | Bad Request |
| 401 | Unauthorized |
| 403 | Forbidden |
| 404 | Not Found |
| 500 | Internal Server Error |

## 7. Frontend Technologies

### HTML
Defines webpage structure and content.

### CSS
Controls webpage styling and layout.

### JavaScript
Adds interactivity and dynamic behavior.

## 8. Browser Rendering

1. HTML parsing creates the DOM.
2. CSS parsing creates the CSSOM.
3. The browser builds the render tree.
4. Layout calculates element positions.
5. Painting draws visual elements.
6. Compositing combines layers.

## 9. Static and Dynamic Websites

A static website generally serves fixed content.

A dynamic website can generate or update content using data, user interactions, or server-side processing.
