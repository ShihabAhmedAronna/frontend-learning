
# Branch Practice

This file was created using a separate Git branch.

## My Understanding

A branch allows developers to make changes independently without directly changing the main branch.

## What I Practised

- Created a new branch.
- Added a new file.
- Saved the changes using a commit.
- Prepared the changes for merging.

## Why Branches Matter

Branches help developers organize their work, test new features, and collaborate without disturbing the main project.
