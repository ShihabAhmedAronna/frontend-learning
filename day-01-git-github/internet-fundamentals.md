
# Internet Fundamentals

## 1. Internet

The Internet is a global network of connected devices that communicate and exchange information.

## 2. Client and Server

- Client: A device or application that requests information.
- Server: A computer or software that provides information and services.

## 3. HTTP and HTTPS

HTTP stands for Hypertext Transfer Protocol.

HTTPS is the secure version of HTTP. It uses TLS encryption to protect communication.

## 4. Domain Name

A domain name is a human-readable website address.

Examples:
- google.com
- github.com
- youtube.com

## 5. DNS

DNS stands for Domain Name System.

It translates domain names into IP addresses.

## 6. IP Address

An IP address identifies a network interface for communication.

- IPv4 uses 32 bits.
- IPv6 uses 128 bits.

## 7. Browser and Web Server

A web browser requests and displays website content.

A web server handles requests and delivers website resources.

Examples of browsers:
- Chrome
- Firefox
- Edge

Examples of web server software:
- Apache
- Nginx

## 8. Frontend and Backend

Frontend is the user-facing part of a website.

Backend handles server-side operations, application logic and data.

Frontend technologies:
- HTML
- CSS
- JavaScript

## 9. Website Loading Process

1. User enters a URL.
2. Browser identifies the server through DNS.
3. A connection is established.
4. Browser sends an HTTP request.
5. Server sends a response.
6. Browser processes HTML, CSS and JavaScript.
7. Browser displays the website.
