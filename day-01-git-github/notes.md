
# Day 01 - Git, GitHub and Markdown

## 1. What I Learned

### Git

Git is a version control system that tracks changes in files and projects.

### GitHub

GitHub is an online platform for hosting repositories and collaborating with other developers.

## 2. Important Concepts

| Concept | Description |
|---|---|
| Repository | Project storage |
| Commit | Saved snapshot of changes |
| Branch | Separate development line |
| Merge | Combining changes |
| README | Project documentation |
| Pull Request | Request to merge changes |

## 3. Git vs GitHub

- Git manages version history.
- GitHub hosts repositories online.
- Both are important in software development.

## 4. Markdown

Markdown is used to format documentation.

Examples:

- `#` creates headings.
- `**text**` creates bold text.
- `*text*` creates italic text.
- `-` creates bullet lists.
- `[text](URL)` creates links.
- `- [ ]` creates a checklist.
